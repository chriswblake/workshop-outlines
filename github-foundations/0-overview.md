## Session Intro

### Certifications Overview (5min)

   - 🐣 **Foundations** - In the beginning
     - Git Version Control
     - Repositories, branching,
     - Collaboration with Pull requests, issues, projects
     - Awareness for other GitHub products
   - 🚀 **Actions** - automate the boring stuff
     - Build, test, deploy
     - Marketplace of premade actions (or build your own)
     - Automate common tasks
   - 🏛️ **Admin** - coding is a team sport
     - Users, teams, orgs, enterprises
     - Cross project boards, packages, runners, copilot
     - Policies (Auth, SSO, rule sets, compliance)
     - Billing (usage, quotas, limits)
   - 🦺 **Advanced Security** - we all make mistakes!
     - Supply chain
     - Secrets
     - Risky coding practices
     - Dashboards and Policies
   - 🤖 **Copilot** - code with natural language
     - Prompt engineering and sample projects
     - Tools, environments, use cases
     - Plans, billing, metrics, ethics

## Session Overview

1. **Intro**

2. **Poll:** What is your favorite naming convention for saving versions or backups?

   - https://forms.gle/gcnYJYsvR6KMNa1Q6
   - backup1, backup2, backup3
   - temp1, temp2, final, final2, final-really, final-approved
   - myproject-24-12-02.zip, myproject-12-12-07.zip
   - I don’t always do backups, but when I do… I delete the old ones.
   - Naming conventions? No way! I use Git! 🤓

3. **Git Version Control**

   - https://www.datacamp.com/tutorial/github-and-git-tutorial-for-beginners
   - In short, it saves you from: backup1, backup2, myproject-24-03-10, src-final, src-final2
   - Decentralized - It can’t be shut down.
   - Enables history, comparison, and parallel development.  
     (aka prevents coworkers from breaking your code mid-process.)
   - DataCamp has a wonderful tutorial on this.  
     (It’s better than the MS learn option. 🤫)

4. **Repository** – A place to put your stuff and track it.

- Create a repo.
- Create a branch.
- Change some files. Example: README.md using MarkDown.

5. **Pull (Merge) Requests** – You do your thing; I’ll do mine. Chat and combine later.

- **Issues/Projects** – Keep your goals (and fires) organized.

  - https://github.com/users/chriswblake/projects

- **Accounts** – Unfortunately, coding is indeed a team sport.
  - https://github.com/pricing
  - Individual – Free/Pro – Free unlimited public and private repos.
  - Organization – Free/Team – Coding is indeed a team sport. ;)
  - Enterprise – Policies across several organizations.
- **Copilot** – the most popular AI pair programmer
  - https://github.com/features/copilot
  - For Srs: Attack the problem holistically.
    - Generate unit tests and docs.
    - Stop making templates.
    - Convert tech requirements into code.
  - For Jrs: Grow. Show tips and things I didn’t know that I didn't know.
    - Code review
    - New languages
    - Best practices
  - IDE, Workspace, Web, Vision, Spark
- **Codespaces** – Never hear “It works on my machine again.”
  - https://github.com/features/codespaces
  - Cloud-based development environment.
  - Based on Dev Containers.
  - I like to say: Project computer (as code)
  - My take: Seconds to onboard
- **Advanced Security** – Avoid and reduce security debt.
  - https://github.com/enterprise/advanced-security
  - Supply Chain (Dependabot)
  - Secret scanning / Push protection
  - Code scanning
  - Alert management / Autofix
